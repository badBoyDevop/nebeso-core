# Contributing to NeBeso Core

Thanks for your interest in contributing to NeBeso Core — the open-source foundation for AI cost tracking.

## What This Repo Is

NeBeso Core contains the generic, reusable Layer 1 components of the NeBeso platform:
- Generic UI components (Badge, Card, Modal, DataTable, etc.)
- Auth pages (Login, Register)
- Base backend models (User, Event)
- API client and utilities

## What We Accept

- Bug fixes in existing Layer 1 components
- Improvements to generic UI components (accessibility, responsiveness)
- Documentation improvements
- New generic utility functions or components

## What We Don't Accept Here

Platform-specific features (dashboards, analytics, budgets, alerts, admin) live in the proprietary NeBeso Platform and are not open for external contribution.

## How to Contribute

1. Fork this repository
2. Create a feature branch: `git checkout -b fix/modal-accessibility`
3. Make your changes
4. Open a Pull Request with a clear description
