# NeBeso Core

Open source foundation for AI cost tracking. Apache 2.0 licensed.

This repository contains the generic, reusable components that power [NeBeso](https://nebeso.com) — UI primitives, auth pages, base models, and API utilities.

## What's Here

- **Frontend** — Generic UI components (Badge, Card, Modal, DataTable, etc.), auth pages, API client, formatters
- **Backend** — Base models (User, Event), health check router, config, database setup

## What's Not Here

The NeBeso platform (dashboards, analytics, budgets, alerts, proxy, admin) lives in the proprietary platform layer.
